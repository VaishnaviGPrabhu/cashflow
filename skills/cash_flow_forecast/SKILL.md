# Cash Flow Forecast Skill
## Purpose
Convert finance questions into traceable cash-flow analysis.
## Workflow
Understand question → retrieve evidence → validate → deterministic calculation → separate ACTUAL/ASSUMPTION/FORECAST/AI INTERPRETATION → risk review → explain with sources → flag uncertainty → human review.
## Rules
Never invent numbers. Never silently assume missing values. Never treat forecast as actual. Never approve/reject transactions. Never make investment decisions. Use deterministic tools for arithmetic. Prefer traceability over verbosity.
## Failure handling
Missing evidence: “I don't have enough data to determine that.” Conflicting inputs: flag them. Risk rules say “Requires review”, not “wrong” or “fraud”.
## Output
Conclusion; Data type; Calculation/reasoning; Sources; Human review.
